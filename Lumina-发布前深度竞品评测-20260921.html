4Lumina 优缺点 · 代码实证版

✅ 真优势（代码里能找到证据）

  • 情绪连续融合是真原创（4.5/5）
    EMA α=0.35 + 迟滞 0.06 + 基线漂移 0.05，9 个 mood 标签二维坐标互转。竞品里 N.E.K.O 是离散状态机，AIRI 无情绪层。证据：electron/pet/emotionFusion.ts
  • 三 Agent 朋友圈剧场感（4.5/5）
    Agent 间自发群聊只进 Moments 朋友圈，不进用户聊天窗。9 个真话题模板带时间窗/随机条件。证据：agentSocialEngine.ts 32KB + momentsStore.ts 3 张 SQLite 表
  • 三 Agent 真独立 Runner
    每个 Agent 独立 LLM endpoint、独立 SOUL.md、独立工具白名单，通过 teamMailbox 异步通信。不是"一个 LLM 塞三个 system prompt"。证据：delegationManager.ts 45KB + team/dynamicWorker.ts 27KB
  • BM25 真自写 + 证据链评分
    k1=1.5 b=0.75 标准公式，中文单字+短语双重索引；5 维加权置信度（conf 0.30 / importance 0.30 / recency 0.15 ...）。证据：hybridMemoryRetrieval.ts + memoryEvidence.ts
  • 26 条沙箱规则真在
    BLOCK×9 / CRITICAL×6 / HIGH×4 / MEDIUM×5 / LOW×2，逐条可枚举。证据：sandboxRules.ts:106-248
  • CI 配置工业级
    三平台 × Node 20/22 + typecheck + vitest + coverage gate 70%/55% + ESLint + build + 三平台 Release 签名。证据：.github/workflows/test.yml
  • 双协议真实
    AGPL-3.0 + Apache-2.0，package.json license 字段正确。比 MIT 多了企业友好路径。

❌ 真短板（README 没告诉你的）

  • 上帝类严重
    agentRunner.ts 157KB（约 4000 行单文件）；渲染侧 GroupChatView.tsx 273KB、ChatPanel.tsx 128KB。第一个 PR 就会被骂。
  • 工具数注水
    README 说 90+，CHANGELOG 说 70+/88+，registry 自己注释"agent 模式 ~25"。grep 全仓 166 处含 CLI/skill，实际注册工具约 50-60 个。
  • TF-IDF 名不副实
    README 吹"TF-IDF + BM25 混合召回"，实际 hybridMemoryRetrieval.ts 里只 push source: 'bm25'，向量分支是空接口。证据：hybridMemoryRetrieval.ts:34-112
  • 两套安全模型并存
    sandboxRules.ts 是 7×8 26 条；securityGuard.ts 是 6×10（注释自承抄 QwenPaw）。registry.ts 同时 import 两个，没有唯一事实源。
  • Windows-only 实际
    CU 键鼠走 PowerShell，shellFileWall 规则全是 C:\Windows\System32 路径；CHANGELOG 自承"仅支持 Windows 10+"，但 README 说三平台、Roadmap 说 v1.3 才支持——三处口径矛盾。
  • 密钥硬编码风险
    agents/lumina/agent.json 第 10 行硬编码真实 LM Studio API Key + 内网 IP。虽 .gitignore 排除，但要 git log --all 确认历史没泄漏。
  • 空壳/临时文件混在主目录
    rechaRunner.ts（10 行 throw 已废弃）、yakRunner.ts（4 行注释）、_unlimit.js（0 字节）、verify-p3-*.ts/js 三个临时脚本。
  • README 截图全是占位
    第 446-454 行六个截图位置全是"*（即将添加截图）*"。开源第一印象靠截图。
  • Issue/PR 模板缺失
    .github/ 下只有 workflows/，无 ISSUE_TEMPLATE/、PULL_REQUEST_TEMPLATE.md。

5用户旅程模拟 · 普通用户 vs 专业用户

👤 普通用户（完全不懂技术）

🌸 Lumina 第一天

0-5 min
下载 NSIS 安装包 → 双击 → 装完。但没有截图、没有 onboarding 视频，点开看到一个 Live2D 猫娘在桌面，第一反应是"这就完了？"
5-15 min
进设置页填 LLM API Key。默认 LM Studio 但普通用户不知道 LM Studio 是什么。DeepSeek 推荐但要去网页注册充值。这一步流失率最高。
15-30 min
配好 Key 后跟 Lumina 聊天。她会主动说"累了吗？"，有表情有语气，惊喜感拉满。但让她"帮我把这个文件拖到桌面"时，CU 第一次可能失败（VLM 要单独配）。
第 1-3 天
新鲜感期。发现她会在朋友圈发动态、和热茶 Yak 群聊，"她背后有团队"的叙事感是独一档。但 29 个面板不知道从何下手，80% 功能不会用。
第 4-7 天
留存分水岭。如果记忆真的能记住"上周说去日本看樱花"，会留下来；如果发现她每次都重新认识你，就卸载。

🐱 N.E.K.O 第一天

  • Steam 一键安装，5 分钟搞定，不用碰命令行。
  • 但仍要自备 LLM Key（推荐阿里百炼免费额度）。
  • YUI 是现成猫娘形象，开箱即有语音。
  • 踩坑：Windows/Mac 云存档冲突；UI 按钮不直观。
  • 普通用户体验：比 Lumina 顺 2 倍，因为 Steam 分发 + 现成语音。

✨ AIRI 第一天

  • PWA 浏览器即开，零安装门槛。
  • 但要自己配 LLM provider + TTS，本地推理要自己换小模型避坑。
  • VTuber 范——她陪你打游戏，不是帮你干活。
  • 普通用户会困惑"这是个玩具还是工具？"

🦞 openclaw 第一天

  • 命令行 curl 一键装，普通用户直接劝退。
  • 没有形象，就是在 IM 里多了个 bot。
  • 要配 20+ 个 channel 之一，非技术用户跑不起来。
  • 普通用户体验：不适合你。

😄 cc-haha 第一天

  • 安装包 5 分钟装好，但 Windows 未签名触发 SmartScreen，用户会以为是木马。
  • 仍要自备付费 API Key。
  • 桌宠只是 4 个 2D 精灵，无语音无情绪。
  • 普通用户体验：这是给程序员用的。

👨‍💻 专业用户（开发者/二次创作者）

🌸 Lumina 第二天

改皮肤
Live2D UGC 导入器已实现（校验 *.model3.json + 复制注册），换皮成本低。但 VRM 口型/视线没接，3D 形象玩法受限。
加 Agent
agents/<id>/{agent.json, SOUL.md, PROFILE.md, AGENTS.md} 四件套声明式定义，这是亮点。但 v1.1.0 才计划"自定义 Agent 创建"，当前要手改目录。
接自己模型
统一模型调用层已做（CHANGELOG 提到），OpenAI 兼容协议即可。.env.example 列了 7 个 provider，接新模型成本低。
写插件
pluginSDK.ts 12KB 存在，但 docs/ 里没有独立 Plugin SDK 文档。要读源码反推，hack 成本高。
代码可维护性
agentRunner.ts 157KB、GroupChatView.tsx 273KB 上帝类，想改核心逻辑要先读 4000 行单文件。这是最大劝退点。
文档质量
docs/ARCHITECTURE / DEVELOPER / FAQ / TROUBLESHOOTING / API 16 端点都齐了，比 N.E.K.O 好，但比 AIRI 的 50 包 monorepo 文档差。

对比：专业用户改 N.E.K.O

  • Python 三进程架构，改后端要起 3 个服务，调试成本高。
  • 插件装饰器 SDK + Steam 创意工坊，UGC 生态已成型。
  • facts.py 293KB 记忆工程，想改记忆要读 29 万行。

对比：专业用户改 AIRI

  • 50 包 monorepo，pnpm workspace，工程最现代。
  • 但要懂 Vue 3 + React Native + Three.js + Rust candle，学习曲线最陡。
  • 插件 proposal 挂了一年多仍 WIP，扩展接口不稳定。

6竞争性与创新 · 抢走谁，被谁打

从 N.E.K.O 手里抢

  • 想要"多 Agent 团队感"的用户：N.E.K.O 是单人格 YUI，Lumina 是 Lumina+热茶+Yak 三人组。如果你想要"我有一个团队在帮我"的感觉，只有 Lumina 给。
  • Windows 单盒用户：N.E.K.O 要 Python 3.11 + 3 进程 + uv sync，Lumina 是单 Electron 应用。
  • 讨厌 Steam 依赖的极客：N.E.K.O 走 Steam 免费分发，Lumina 走 GitHub Releases + 双协议。

从 AIRI 手里抢

  • 不想要 VTuber、想要工作伙伴的人：AIRI 陪你打游戏，Lumina 帮你拖文件。
  • 中文用户：AIRI 是英文社区主导，Lumina 中文母语。

从 openclaw 手里抢

  • 不想要命令行、想要形象的人：openclaw 是无头 gateway，Lumina 有 Live2D 猫娘。
  • 但注意：这不是抢，是互补。很多用户会 openclaw 做后端 + Lumina 做前端。

从 cc-haha 手里抢

  • 不想要 Claude Code 绑定、想要陪伴感的人：cc-haha 主菜是编码，Lumina 主菜是陪伴。
  • 担心 DMCA 风险的企业用户：cc-haha 反向工程 Claude Code，Lumina 模型中立。

⚔️ Lumina 会在哪些点上被吊打？

被 AIRI / openclaw 吊打

# system — 系统工具

当用户需要查询时间、截屏、发送通知或打开文件时使用本技能。

## 工具

| 工具名 | 描述 |
|--------|------|
| `datetime` | 获取当前时间。 |
| `screenshot` | 截屏。 |
| `system_info` | 查询系统信息（OS、CPU、内存等）。 |
| `notification` | 发送桌面通知。 |
| `open_file` | 用默认程序打开文件/URL。 |

## 使用守则

1. **screenshot 先问**——截屏涉及隐私，需要用户确认。
2. **notification 谨慎**——不要频繁弹通知打扰用户。

# pomodoro — 番茄钟提醒

当用户需要专注工作、启动番茄钟、查询专注进度或停止计时提醒时使用本技能。
默认 25 分钟工作 + 5 分钟休息，到点通过系统通知提醒。

## 工具

| 工具名 | 描述 | 参数 |
|--------|------|------|
| `pomodoro_start` | 启动番茄钟（工作+休息），到点系统通知提醒。 | `work_minutes`(默认25) `break_minutes`(默认5) |
| `pomodoro_status` | 查询当前番茄钟状态与剩余时间。 | 无 |
| `pomodoro_stop` | 停止当前番茄钟。 | 无 |

## 使用示例

```
用户: "我要专注工作 25 分钟"
  → pomodoro_start(work_minutes=25, break_minutes=5)

用户: "我这个番茄钟还剩多久？"
  → pomodoro_status()

用户: "停下番茄钟"
  → pomodoro_stop()
```

## 使用守则

1. **同时只跑一个**——启动新的前如果已有在运行，会提示先 stop。
2. **通知为主**——到点弹系统通知，状态查询用 `pomodoro_status`。
3. **主进程单例**——状态保存在主进程内存，应用重启后番茄钟不保留。

## 实现说明

- 用 `setTimeout` 计时，工作阶段结束自动切到休息阶段，休息结束自动停止。
- 通知优先使用 Electron `Notification`；非主进程/不可用时回退到 console。
- 模块级状态存储：当前阶段、开始时间、总时长、定时器句柄。

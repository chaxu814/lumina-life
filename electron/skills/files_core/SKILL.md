# files_core — 文件操作（核心）

当用户需要读取、写入、编辑、列出或搜索文件时使用本技能。

## 工具列表

| 工具名 | 描述 |
|--------|------|
| `file_read` | 读取文件内容。支持 `start_line` / `end_line` 读取指定行范围。 |
| `file_write` | 创建或覆盖文件。谨慎使用——先读后写。 |
| `file_edit` | 查找替换文件中的文本。比 `file_write` 更安全——只改指定部分。 |
| `file_list` | 列出目录内容（支持 glob 模式）。 |
| `file_search` | 按内容/模式搜索文件（grep 风格）。 |

## 使用守则

1. **读文件前不用问**——用户要你读就读。
2. **写文件前先读**——如果文件已存在，先读再决定是 edit 还是 write。
3. **编辑优先**——尽量用 `file_edit` 而非 `file_write`，避免覆盖。
4. **路径约定**——相对路径从 agent 工作区解析；绝对路径直接用。

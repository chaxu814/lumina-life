# memory — 记忆系统（三层 + 向量检索）

当用户需要记住信息、查询历史、或回顾之前对话时使用本技能。

## 工具

| 工具名 | 描述 |
|--------|------|
| `memory_save` | 保存关键信息到长期记忆。 |
| `memory_search` | 语义搜索记忆（向量 + BM25 混合）。 |
| `memory_get` | 按 key 读取特定记忆。 |
| `memory_all` | 列出所有记忆块。 |
| `memory_summarize` | 总结当前记忆内容。 |

## 使用守则

1. **自动存档**——用户偏好、关键决策、已完成事项，及时调用 `memory_save`。
2. **先查再用**——用户说"还记得吗"时，先 `memory_search` 再回答，不凭上下文猜测。
3. **不存敏感信息**——API Key、密码等除非用户明确要求，否则不入记忆。

# web_search — 搜索与抓取

当用户需要查找信息、获取网页内容或访问 URL 时使用本技能。

## 工具

| 工具名 | 描述 |
|--------|------|
| `web_search` | 搜索引擎查询。返回摘要 + URL。适合查找实时/新鲜信息。 |
| `web_fetch` | 抓取 URL 内容（HTML → 文本）。适合读取文档/文章。 |
| `browser` | 启动浏览器。可截图、点击、填表单。需要交互操作时用。 |

## 使用守则

1. **先搜再取**——不确定 URL 时先用 `web_search` 找到链接，再用 `web_fetch` 获取内容。
2. **能搜的不猜**——API 参数、版本号、价格等实时信息，先搜索不凭记忆。
3. **browser 有节制**——只有需要 JS 渲染/登录/交互时才用 browser。
4. **fallback 链**——`web_search` 失败 → `web_fetch` 兜底 → `browser` 最后。

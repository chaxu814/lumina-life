# git — Git 版本控制

当用户需要查看仓库状态、提交、历史或差异时使用本技能。

## 工具

| 工具名 | 描述 |
|--------|------|
| `git_status` | 查看仓库状态（改动、暂存、未跟踪文件）。 |
| `git_commit` | 创建提交。 |
| `git_log` | 查看提交历史。 |
| `git_diff` | 查看文件差异。 |

## 使用守则

1. **先 status 再 commit**——提交前用 `git_status` 确认改了什么。
2. **commit message 要明确**——中文写清楚改动内容。
3. **不 push**——除非用户明确要求，不执行 `git push`。

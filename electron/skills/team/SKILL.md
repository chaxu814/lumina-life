# team — 团队协作

当用户需要与其他 agent 协作、委托任务或切换工作模式时使用本技能。

## 工具

| 工具名 | 描述 |
|--------|------|
| `delegate_to` | 委托任务给另一个 agent（Yak / 热茶）。 |
| `mode_switch` | 切换工作模式（chat / agent / developer）。 |
| `mode_status` | 查看当前工作模式。 |
| `team_context` | 查看团队共享上下文。 |
| `delegate_chain` | 创建多步委托流水线。 |
| `write_notice` | 在公告板写消息给其他 agent。 |
| `read_notices` | 读取公告板上的消息。 |
| `save_context` | 保存团队共享上下文。 |
| `load_context` | 加载团队共享上下文。 |

## 使用守则

1. **委托前想清**——只委托需要其他 agent 专长能力的任务（Yak 写代码、热茶审阅）。
2. **给上下文**——委托时提供足够背景和目标，不要只说"帮我处理这个"。
3. **公告板用途**——用于跨 agent 的异步消息；重要决策才写。

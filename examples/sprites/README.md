# 做一只自己的桌宠 · 精灵表 UGC

> **一句话**：不用会 Blender、不用会绑 3D 模型、不用懂 Live2D。
> 一张 PNG + 一个 JSON，你就能做一只只属于你的 Lumina。

---

## 为什么这条路径值得存在

桌宠这个品类靠「用户自己做一只」传播。但现有项目给的三条路门槛都太高：

| 形态 | 门槛 | 业界现状 |
|---|---|---|
| Live2D | 会 Cubism、会建模、会绑定参数 | 平台创意工坊分发（需要画师） |
| VRM / MMD | 会 Blender、会绑骨 | 平台创意工坊分发（需要 3D 美术） |
| **精灵表** | **会画就行** | —— |

同类开源项目已经验证了「用户自己做宠物」这条路：fork 与 star 的比例很高，
说明大量用户就是 fork 下来改成自己的形象，而且成熟的精灵表规格在这条路上被反复沿用。
**精灵表是唯一能让小学生也参与进来的形态。**

我们把它做进主线，是因为它同时解决两件事：
用户的创作门槛，和我们自己的授权问题（见 `THIRD_PARTY_NOTICES.md`——
仓库不再携带任何 Live2D 模型资产，形象一律走「用户自备 + 导入」）。

## 规格：8 列 × 9 行，61 帧

| 行 | 动作 id | 名称 | 帧数 | 说明 |
|---:|---|---|---:|---|
| 1 | `idle` | 待机 | 6 | 轻微呼吸起伏，偶眨眼 |
| 2 | `run-right` | 向右跑 | 8 | **左向由镜像自动补出** |
| 3 | `wave` | 挥手 | 4 | 抬手挥手致意 |
| 4 | `jump` | 跳跃 | 5 | 起跳-滞空-落地 |
| 5 | `fail` | 失败 | 8 | 捂脸、垂头、叹气 |
| 6 | `wait` | 等待 | 6 | 踱步、左右张望 |
| 7 | `work` | 工作 | 8 | **绑定真实 Agent 运行状态** |
| 8 | `look-up` | 视线向上 | 8 | 跟随鼠标 |
| 9 | `look-down` | 视线向下 | 8 | 跟随鼠标 |

两条省事的设计：

- **左跑靠镜像**。跑动本来就是左右对称的，逼你再画一套是纯浪费。
- **每行帧数不同，列数统一 8**。短行左对齐、多余列留空，
  切片器不需要知道每行有多少帧，规则简单到能写在第一屏。

## 三条上手路径

### 路径 1：单张静态图（1 分钟）

一张 PNG 就够。会有呼吸浮动效果，不算完整动画但立刻能用。

### 路径 2：模板起步（10 分钟，推荐）

```bash
# 生成一张 8×9 的空白模板：2048×2304，有效帧格子打了浅蓝底色
node scripts/make-sprite-template.mjs

# 想小一点（1024×1152，单帧 128）
node scripts/make-sprite-template.mjs --frame 128
```

模板里已经标好了每行的动作名、帧数和帧序号，浅蓝格子是要画的，浅灰格子不用管。
在任意绘图软件里覆盖上去，导出成 PNG，和 `sprite.json` 放一起即可。

> 这个脚本是**零依赖**的（PNG 编码器是手写的，只用 Node 内置 zlib），
> 克隆下来就能跑，不需要在系统 Node 下重建 sharp。

### 路径 3：让 AI 出图（约 10 分钟）

把下面这段连同 `sprite.json` 一起喂给任意绘图 AI：

```
做一张像素风桌宠精灵表，规格严格如下：

图集：8 列 × 9 行，单帧 256×256，整体 2048×2304，透明背景。
角色：[在这里描述你的角色]

逐行要求（每行是一个动作，第 1 帧到第 N 帧必须连贯）：
  行1 待机 idle 6 帧：轻微呼吸起伏，第 4 帧眨眼
  行2 向右跑 run-right 8 帧：手脚交替，循环无缝
  行3 挥手 wave 4 帧：抬手挥动
  行4 跳跃 jump 5 帧：起跳 / 上升 / 滞空 / 下落 / 落地
  行5 失败 fail 8 帧：捂脸、垂头、叹气
  行6 等待 wait 6 帧：踱步、左右张望
  行7 工作 work 8 帧：专注敲键盘，循环无缝
  行8 视线向上 look-up 8 帧：抬头，眼睛跟随
  行9 视线向下 look-down 8 帧：低头，眼睛跟随

要求：
  - 角色在每帧中保持在同一水平基线上，不要上下漂移
  - 不要画格子线，不要写文字
  - 跑动和工作的循环要能无缝首尾相接
  - 未使用的格子（第 1/4/6 行的第 7、8 格）留完全透明
```

生成后按路径 2 的方式裁到正确尺寸，导入即可。

## 导入

**设置 → 形象 → 导入 → 选择 spritesheet**

导入器会校验：
- 图集尺寸能否被单帧宽高整除
- 是否有可执行文件混入
- 是否是白底图（多半是导错了）
- 单文件体积上限

全程本地处理，**不上传、不消耗任何模型额度**。

## 目录结构

```
你的精灵表/
├── sprite.json        ← 清单：名字、作者、许可、帧宽高、动作表
└── sheet.png          ← 图集
```

`sprite.json` 模板见 [`TEMPLATE/sprite.json`](TEMPLATE/sprite.json)。

**`license` 字段请务必填。** 你的作品你说了算，但写清楚授权
（`CC0` / `CC-BY-4.0` / 保留所有权利）才能被别人安全地用。

## 提交你的作品

我们希望这个目录长成一个**社区资产库**：

- 精灵表是纯像素文件，版权归属清晰，不像 Live2D 模型有额外的 SDK 条款
- 贡献一只猫娘 = 一次免费拉新，而且作品会带着作者署名被传播

提 PR 时请：
1. 放进 `examples/sprites/<你的名字>/`
2. `sprite.json` 里 `name` / `author` / `license` 填全
3. 确认你对自己的像素有权利（AI 生成的也要在 README 里注明用的哪个模型）

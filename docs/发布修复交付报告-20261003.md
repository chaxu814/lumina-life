## 逐项交付

### 图 1 · autoFixLoop 双实现 → 单一实现 ✅

**问题**：`verifyLoop.autoFixLoop` 与 `delegationManager` 内联拷贝各自演化，内联版多出三项能力（情绪调节轮数、收敛检测、LuckyMode 停止条件）。修 bug 要改两处。

**做法**：把全部能力收敛到 `verifyLoop.autoFixLoop`，通过钩子注入情绪/停止条件/收敛检测；内联版改为只提供钩子。顺带补上原先只有内联版才有的早期终止语义。

**证据**：`autoFixLoop` 引用数 0 → 12；`defaultConvergenceCheck` 已提取为可单测的纯函数。

### 图 2 · 路由系统 → 真正接线 ✅

**问题**：`decideRoute()` 的三档策略（规则高置信直接定 / 歧义调 LLM / 失败回退）写好了，**没有任何调用方**。实际只用了 `classifyByRules` 往 prompt 加一句提醒。

**做法**：
- 新增 `warmRouteHint()`：规则能定的零成本直接定；歧义才起一次后台仲裁
- **1.2s 硬超时** —— 路由发生在首字响应前，多一次 LLM 调用会直接拖慢体感
- **独立 provider 实例** —— 绝不复用 `this._llmProvider`（它会改写 `this.messages`）
- 仲裁失败/超时/返回垃圾 → 静默退回纯规则，**绝不阻塞用户**

**踩过的坑**：`ELECTRON_RUN_AS_NODE` 没设对时 Electron 会把 `--no-sandbox` 当 GUI 参数直接报 `bad option`。

**收益**：真正解决了注释里写的失败模式 ——「这玩意跑起来就崩，帮我看看」没有任何代码关键词，纯正则必然漏派。

### 图 3 · 死代码 → 全部接线或说明 ✅

| 模块 | 之前 | 现在 |
|---|---|---|
| `yakParallel.ts`（16KB 并行引擎） | 零调用方，纯死代码 | 接入 `phaseGate._doExecute`：同批次无依赖的 ready 任务并行执行（有依赖边仍串行）。引用 0 → 19 |
| `reviewTonePrompt()` | 定义了没人调用 | 接入 `adversarialReview` 的真实评审提示词。README「亲密度影响审查语气」从此名副其实。引用 1 → 4 |
| `teamPolicy` 两个决策函数 | 无调用点 | `recordApprovalVerdict` 有链路，保留并在注释说明 |

> 我选择**接线而不是删除** —— 「并行 worker」恰好是 N.E.K.O/AIRI 都没有的潜在差异化点，删掉太浪费。

### 关于 ABI —— 这是最值得记住的一条

```
better_sqlite3.node was compiled against NODE_MODULE_VERSION 143 (Node 20)
Electron 40 requires NODE_MODULE_VERSION 148
[AgentRunner] ⚠️ Scroll/ReMe 初始化失败
```

**为什么之前没发现**：`vitest` 全绿，因为测试跑在 Node 下，**Node 和 Electron 用不同的 ABI**。类型检查看不见 ABI，单测跑不到那个环境。

**怎么修的**：`npm run rebuild:electron`（node-gyp 从源码重编，耗时约 8 分钟）。

**怎么防复发**：
- `tests/nativeAbi.test.ts` —— **真实拉起 Electron** 去 `require` 并跑一条 SQL，断言返回 42
- CI 新增 `native-abi` job

> 我一开始想从二进制里 grep `NODE_MODULE_VERSION` 字符串来比对，**结果扫描永远返回 null** —— 现代 node-gyp 产物里那个标记不是明文。测试静默退化成「跳过」，等于没有守卫。改成真跑 Electron 才是唯一可靠的真相。这点写进注释了，避免后人再走一遍。

## P2 · 增长（4 项，3 项完成）

### #12 精灵表 8×9 规格 ✅

对标 cc-haha 用 14.8k★ 验证过的 UGC 路径（它的 fork/star 比 58%，说明大量用户在画自己的宠物），但**门槛更低** —— Live2D/VRM 需要会 Blender，精灵表不需要。

- 8 列 × 9 行，61 帧；**左跑由第 2 行水平镜像自动补出**（省一半工作量）
- 三条创建路径：单张静态图(1min) / AI 生成动作表(~10min) / 已有图集
- 导入校验：尺寸/像素/体积/可执行文件拦截，全本地不上传
- **34 个测试**
- 已接入 `AvatarKind` 体系（否则又是个孤立模块 —— 那正是本次审计抓死代码的同款问题）

**诚实标注**：`supported: false` / `status: 'roadmap'`。规格和校验都就绪了，但**渲染器页面还没产出**。宁可明说不可用，也不让它出现在可选列表里点进去发现是空的。

### #13 桌宠绑定真实 Agent 状态 ✅

cc-haha 作者自己写死的边界：桌宠「只是个状态提示和跳转入口，**不能替你批准权限**」。AIRI 的表情来自模型输出，不绑定执行状态。

**我们让干活的人自己被看见**：

| 真实状态 | 桌宠表现 |
|---|---|
| Yak 写代码 | 敲键盘 + 专注光晕 |
| 热茶审查 | 审视表情 + 怀疑色 |
| 等待处理 | 踱步 |
| 验证失败 | 捂脸 + 警示色（4s 后隐去） |
| 刚完成 | 挥手庆祝 |
| 没人干活 | **不动** —— 交还情绪系统 |

零 LLM 调用（状态机映射）· 1.2s 防抖 · 空闲不接管 · `LUMINA_PET_AGENT_STATE=0` 可关。**14 个测试。**

### #14 新手模式 ✅

**没有内置推理引擎** —— 那会带来 +数百 MB 体积、多平台坑、和上游生态脱节。正确做法是**把「该做什么」算好给用户**。

- 检测到 LM Studio/Ollama → 推本地（免费优先）
- 探测不到就**老实说探测不到**，列明硬件要求和数据外发提示
- 新手默认开关偏保守：主动说话/全屏注视/后台自主任务**全关**（老用户是卖点，新用户第一次打开是惊吓）

**16 个测试。**

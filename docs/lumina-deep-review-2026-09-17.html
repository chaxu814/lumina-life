⑦ 深度体检：真正站得住的优点
  1. 「意识同帧驱动身体」机制依旧是最锋利的差异点，且 v0.2 把它做厚了：表演 DSL（LLM 下高层指令而非裸参数）+ 五层加权软混合 + 五元音口型（文本定形、真实音频能量定张度）+ 模型无关的全参数语义 profile。三家都没把它当第一卖点。
  2. 多 Agent「团队群像」独一份：固定三人 + 委托流水线（写→审→修闭环）+ 群聊/早安/朋友圈/梦境/真人秀/亲密度，陪伴类里没有第二个。
  3. 生命感系统从「状态机」升级到「内驱力」：energy/social/curiosity/comfort 内驱力指导自主行为，LLM 不可用时也不僵（困了睡、无聊撒娇、好奇走动），情绪有 EMA 惯性/迟滞/动量而非硬切。
  4. Computer Use 已反超 N.E.K.O 自研面：Set-of-Mark、zoom、batch、alpha-trim、全局急停、DPI 免疫归一化、中文输入、高危硬拦截——这些在陪伴类里属领先；N.E.K.O 主要靠 CUA + OpenClaw 组合。
  5. 安全纵深是陪伴产品里罕见的：六层防线、7 级×8 类、审批/访问控制/沙箱/密钥加密/全局急停，意识接近 OpenClaw（N.E.K.O 甚至默认带 Steam64 遥测，虽可关）。
  6. 工程质量扎实且交付密度高：TS strict、470 单测、纯逻辑模块依赖可注入、三端 build、工作树干净、密钥治理、清醒的工程治理文档；约 7 周 11 万行自有代码。
  7. 本地优先 + 异构模型容错：LM Studio/Ollama 可全离线；今天的 modelCompat 让纯聊天/纯文本模型也不再一接就崩，降低本地用户门槛；双许可对个人和商业都友好。
  8. 办公生产力面最宽：70+ 工具 + CLI + REST API + 文件/git/LSP/OCR/深度研究，比另两家「更能干活」。
⑧ 深度体检：仍然存在的问题（直说，按严重度）
P0 · 阻塞「成为产品」
  • 仍未发布：无 remote、0 Release、0 外部用户。N.E.K.O 已上 Steam 且手机内测，窗口在收窄。
  • 全双工实时语音差最后一公里：状态机/IPC 全好，但麦克风流式接入、中文流式 STT（默认 whisper-tiny.en 不识中文）、TTS 逐句回调未接——这恰是 N.E.K.O 最出体感的第一公民能力。
  • 大量「逻辑就绪、真机未验证」：SoM 渲染、alpha-trim 缩放下是否裁到模型、全双工、presence 人脸、UGC 加载、透明窗修复都在等真机，当前无 GUI 自测环境。
P1 · 能力深度 / 覆盖
  • 原生 Claude / Gemini / Azure 仍不支持：providerAdapter/unifiedChat 已写好且有单测，但主链路零调用（没接线）；全系统只讲 OpenAI 兼容。
  • 形态单薄：仅 Live2D，无 VRM/MMD（N.E.K.O 五形态、AIRI 有 VRM）；内置仍 Mao 一款，UGC 导入器虽在但缺授权清晰的默认形象。
  • 广度 > 深度、功能蔓延：30+ 顶层模块（luckyMode/dream/realityShow/mission/timeCapsule/游戏化/7 角色…），单点对拼都不够深。
  • 6 个 IM 渠道与 OpenClaw 桥接都是早期 adapter，真实联调待做。
P2 · 工程 / 打磨
  • 5 个千行单体：agentRunner 2665、main 1669、systemIpc 1569、petWindow 1555、proactiveEngine 1443；82 处 TODO/FIXME；主 bundle 约 11MB。
  • 内驱力/情绪跨会话不持久（drives 为内存单例，重启回基线）。
  • 仅 Windows 优先：无 Web/PWA/移动/Docker/headless；better-sqlite3 发布前需按 Electron ABI electron-rebuild。
  • 三项技术决策仍等拍板：视觉路线（本地 9B+SoM / 云强模混合 / 自托管 UI-TARS）、执行层（PowerShell / nut.js）、默认权限姿态。
⑨ 逐对手：赢面与短板
vs N.E.K.O（最直接对手）
你占优：同帧驱动身体的机制厚度、多 Agent 团队群像、安全纵深、办公工具面、自研 CU 完整度、本地模型容错。
你落后：全双工实时语音的真机打磨、五形态 Avatar+动捕、零配置开箱、跨端同一人格（对方手机内测+Docker）、14+ 供应商与免费模型、Steam 工坊 UGC 闭环、已发布的产品化与社区。
主动搭话/窥屏/五维记忆/猫娘桌宠高度重合——差异必须靠「驱动身体 + 团队群像」讲得更锋利，且尽快发布。
vs AIRI（不同赛道：游戏 VTuber）
你占优：桌面办公生产力、多 Agent 团队、中文本土渠道、情感与安全纵深、CU 操控桌面。
你落后：「AI 真会玩游戏」王牌、VRM、Web/PWA/iOS 触达、monorepo 可复用 npm 包（xsai/unspeech/DuckDB）、WebGPU/CUDA/Metal 本地推理、4.9 万星社区与国际化。

vs OpenClaw（不同物种，别正面打）

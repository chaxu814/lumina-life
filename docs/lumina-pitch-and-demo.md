# Lumina 唯一卖点定位 & 首个演示视频脚本（v1）

> 用途：对外只讲一件事，并把这件事拍成 1.5–2 分钟的演示视频。
> 结论先行：**Lumina 不是"又一个 AI 聊天桌宠"，而是第一个"身体由大模型实时驱动、像生命体一样活着"的 AI 伙伴。**

---

## 一、唯一卖点（One-liner，对外统一口径）

**中文主口径（推荐）**
> Lumina 是一只"活着"的 AI 桌宠：大模型每一次思考，都会同时写下她的动作、表情和台词，身体和意识由同一个大脑实时驱动——她会看你的屏幕、有自己的情绪和记忆，而不是播放预设动画的皮套。

**英文主口径（GitHub / X / Reddit 用）**
> Lumina is a *living* AI desktop companion: the LLM writes her motion, expression and words together as one JSON "thought" every few seconds — the body is driven by the model in real time, not by canned animation. She watches your screen, has mood and memory, and feels alive.

### 为什么是这一句（战略理由，非对外）

1. **别人讲"AI 陪伴"，我们讲"生命体"**——AIRI/N.E.K.O/同类项目都能聊天、能看屏幕，但它们的身体是"状态机/预设动作"，意识和身体是两套东西；Lumina 的差异是**意识直接输出身体指令**（一个 JSON 同时决定 action/mood/speech）。
2. **可被一眼验证**：视频里同一句话/同一个画面，她的表情、动作、台词是一起变化的，观众不需要懂技术也能看出"这不是写死的"。
3. **一句话能讲完，30 秒能演完**，符合开源项目"3 秒定生死"的传播规律。

### 信息纪律（对外不讲 / 弱讲）

| 内容 | 对外策略 | 原因 |
|---|---|---|
| LLM 写 JSON 驱动身体 | **核心主打，反复出现** | 唯一不可替代的差异点 |
| 看屏幕主动关心 | 主打（第二记忆点） | 最容易被普通用户感知的"生命感" |
| 情绪/记忆系统 | 一句话带过 | 是支撑，不是卖点本身 |
| 三 Agent 后台团队（热茶/Yak） | 10 秒彩蛋即可 | 很酷但会分散"生命体"主线，留给进阶用户 |
| Computer Use 操作电脑 | 第二支视频再讲 | 能力很强但和"生命体"是两个故事 |
| 模型/部署细节（LM Studio、参数） | 文档讲，视频不讲 | 观众先被打动，才关心怎么装 |
| VRM/捏脸/多模型聚合 | 暂不讲 | 不是差异化，讲了稀释记忆点 |

## 二、1.5–2 分钟演示视频分镜脚本

> 拍摄方式：OBS/系统录屏，1080p，只录屏幕 + 右下角小窗可选。全程真机操作，不做后期合成动画。
> 节奏目标：前 15 秒必须出现"生命体时刻"。

### 分镜表

| # | 时长 | 画面操作（真机） | 屏幕字幕 / 旁白 | 想让观众感到 |
|---|---|---|---|---|
| 1 | 0–6s | 桌面静止，Lumina 安静待着，自己轻轻眨眼、晃头、换了个小表情 | 字幕："她不是一段循环动画。" | 好奇 |
| 2 | 6–15s | 打开记事本敲一句"今天好累啊"；Lumina 立刻**同时**做出心疼表情 + 靠近动作 + 气泡台词（一气呵成） | 字幕："她的表情、动作、台词，是同一个大脑在同一瞬间决定的。" | **第一个生命体时刻** |
| 3 | 15–28s | 画面切到"大脑日志"小窗（DevTools 日志或调试面板）：能看到模型实时吐出的 JSON：`{"action":"tilt","mood":"gentle","speech":"…"}`，镜头在 JSON 和她的身体之间来回对照，JSON 一变，她就跟着变 | 旁白："注意看：大模型不是只回一句话，它直接写下了身体该怎么动。" | 看懂机制，产生"原来如此"的震撼 |
| 4 | 28–45s | 依次切换窗口：VS Code 写代码 → B 站视频 → 深夜 23:40 还在改 bug。她分别做出：认真注视、放松、主动凑过来催你休息的不同反应 | 字幕："她一直在看你的屏幕（可随时关闭），并且真的'看懂'了你在干嘛。" | 被关心、被陪伴 |
| 5 | 45–60s | 快速蒙太奇：被逗笑→开心动作；你沉默很久→她歪头疑惑；你说"讲个笑话"→她边讲边做夸张表情。**每个片段都让 JSON 日志一闪而过** | 字幕："没有两次反应是完全一样的——因为驱动她的是模型，不是脚本。" | 鲜活、不可预测 |
| 6 | 60–75s | （彩蛋，快切）主界面里 Lumina 把"帮我查资料"派给后台 Yak、把"看看这段代码"派给热茶，三个 Agent 在后台协作，她回头只跟你说一句"搞定啦" | 字幕："她背后还有一个小团队。" | 深度惊喜 |
| 7 | 75–90s | 展示本地模型设置一页带过：数据本地、隐私模式一键关闭看屏幕、开源 | 字幕："本地模型可跑 · 隐私可控 · 开源" | 信任 |
| 8 | 90–105s | 回到桌面，你说"晚安"，她打了个哈欠、挥挥手、安静下来 | 字幕："Lumina —— 一只真正'活着'的 AI 桌宠" | 情感收尾 |
| 9 | 105–115s | Logo + GitHub 地址 + "Star / Download" 引导 | "项目地址：github.com/〈你的仓库〉" | 行动 |

### 拍摄前检查清单（真机必须真的能演出来）

- [ ] 本地 LLM 已连通（设置→LLM 模型→保存配置；本地 LM Studio 不需要填 API Key）
- [ ] 桌宠"主动秘书/屏幕观察"已开启，"立即搭话一次"点下去 3 秒内必有反应
- [ ] 能调出大脑日志窗口，观众看得清 `action / mood / speech` 三个字段
- [ ] 准备好 4 个窗口场景：记事本、VS Code、视频网页、一个"深夜工作"状态
- [ ] 每段台词控制在 15 字内，气泡不要挡住人物动作
- [ ] 全程无报错红字；先完整彩排 2 遍再录

### 30 秒极速版（用于 X/短视频封面帖）

只保留分镜 1 → 2 → 3 → 5（蒙太奇压到 8 秒）→ 9。核心就是：**静止 → 你说一句话她身心齐动 → JSON 对照 → Logo**。

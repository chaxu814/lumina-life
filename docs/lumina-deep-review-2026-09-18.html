⑤ 两种视角：普通用户拿到手，会经历什么；专业用户打开它，会看到什么
普通用户视角（想要一个「会陪我、能帮我点小忙」的桌面伙伴）
下载安装安装包 151MB / 绿色版 204MB，装完约 571MB。未签名，首装会弹 SmartScreen「未知发布者」，需要点「更多信息 → 仍要运行」，这一步会劝退很多非技术用户。
第一印象安装后桌面、开始菜单、任务栏、托盘都是纸袋少女图标（本轮新做）；Live2D Mao 置顶悬浮、会主动搭话，三角色群聊有「人」的感觉。
上手门槛最大摩擦 要自带模型 Key 或本地模型，不像 N.E.K.O 有免费开箱模型；配置项多、专业词多，普通用户容易在「模型/供应商」这一页卡住。
日常使用之前「隔一段时间小卡一下」已修：帧率默认 30、可在设置主面板直接调；稳态约 775MB 内存（Electron 正常水位，但对低配机偏重）。
语音体验中文有坑 全双工已能跑，但离线 Whisper 是 tiny.en 不识中文，中文语音主链路默认走联网 Web Speech；断网或浏览器内核语音服务不稳时，中文语音就不可用。
预期管理「梦境」「真人秀」是 25 个模板随机拼接（代码注释已如实标注 NOT LLM），记忆只塞约 50 字；作为「彩蛋/实验」有趣，但不能对外宣称「她真的活着」。内置形象只有 Mao 一款。
专业用户 / 开发者视角（评估要不要用、改、二开、贡献）
代码质量TypeScript strict、547 测试通过、纯逻辑模块依赖可注入、三端构建、双许可（AGPL/Apache）；工程意识和测试密度在同类里偏上。
可扩展面插件 SDK、MCP、技能市场、渠道 adapter、UGC Live2D 导入、CLI/REST、30+ 后端模块；「能干活」的面很宽（约 60 工具：文件/git/LSP/OCR/浏览器/深度研究）。
安全纵深六层防线、7 级×8 类、审批/访问控制/沙箱/密钥加密/全局急停；Computer Use 有 SoM/zoom/batch/alpha-trim/DPI 免疫/高危拦截——在陪伴类里罕见。
技术债实打实 10 个千行/超大文件（GroupChatView 267KB、agentRunner 154KB）；核心 ReAct 循环 154KB 却只有 4.1KB 测试；63 处 TODO；无 CI 覆盖率门禁。
记忆架构SQLite + 混合检索；默认 TF-IDF（零依赖），可选 Ollama 向量 / embedding-server；分层不如 N.E.K.O 五维记忆工程化；内驱力/情绪仍是内存态、重启回基线。
平台/发布仅 Windows x64；无 Web/PWA/移动/Docker；better-sqlite3 需按 Electron ABI rebuild（打包已自动处理，纯 Node 跑测试会报 ABI 警告但不致命）；无 CI、无 Release、无贡献者。
一句话概括两类用户：普通用户会被「外形 + 群像 + 主动陪伴」打动，但卡在模型配置、签名警告、中文语音三个门槛；专业用户会认可架构理念、安全纵深和工具面，但会指出核心循环测试薄、超大文件、记忆分层与情绪持久化、渠道未联调。两类用户的交集结论一致：现在最缺的不是功能，是「一键开箱 + 真机打磨 + 公开」。

⑧ 短 / 中 / 长期趋势：Lumina 会走向哪里
短期（0–3 个月）：发布即最大杠杆
  • 赛道窗口在收窄：N.E.K.O 已上 Steam 破万、大厂桌宠密集落地。每多闭一个月，先发位就少一寸。
  • 建仓 + Release + 真机演示视频，用真实用户反馈替代闭门堆功能。
  • 代码签名 / 自动更新：消掉 SmartScreen 警告（普通用户第一道坎）。
  • 一轮真机回归：透明窗、alpha-trim 在 125/150% 缩放、全双工中文、UGC 导入。
  • 定中文 STT 方案（本地中文模型或浏览器/云），让主链路不依赖联网 Web Speech。
  • 降低开箱门槛：内置/赠送一套免费可用的默认模型或引导配置。
中期（3–12 个月）：把差异点磨到「不可替代」
  • 把「同帧驱动身体 + 三 Agent 团队群像」做成一句话记得住、视频里看得到的招牌；梦境/真人秀要么真接 LLM、要么明确标注「彩蛋/实验」。
  • 内驱力/情绪持久化：让「越处越懂你」跨重启成立（现在 drives 是内存态、重启回基线）。
  • 记忆分层向 N.E.K.O 看齐：本地向量/语义召回做成默认且不依赖 Python sidecar。
  • 补 1–2 个授权清晰的默认形象，VRM 排期；核心 agentRunner 补集成测试（154KB 仅 4.1KB 测试）。
  • 真机打通 1–2 个渠道（QQ 最成熟），渠道从「骨架」变「能用」。
  • 拆超大文件、加 CI 覆盖率门禁，为社区贡献做准备。
长期（1–3 年）：在大厂平台化之前，守住「人格 + 数据主权」
  • 品类从「聊天机器人」彻底转向「观察式本地代理」；通用执行会被大厂/OpenClaw 做成水电煤，人格与陪伴体验才是开源护城河。
  • 不与 OpenClaw 正面打执行/渠道，用 A2A/MCP 把它当手脚；不追 AIRI 的游戏陪玩；守住「中文、本地、有团队、有身体、有安全纵深」的卡位。
  • 本地优先 + 数据不出本机，是对抗云大厂的核心理由（隐私焦虑是 2026 持续趋势）。
  • 可选商业化：Steam/独立分发、形象工坊与创作者生态、可复用的「生命感引擎」npm 包（学 AIRI 的 monorepo 子包策略）。
  • 风险：大厂把桌宠做成系统标配；应对是把「灵魂深度 + 可移植/可拥有」做到平台不愿做的程度。
⑨ 深度体检：真正站得住的优点
  1. 「意识同帧驱动身体」是最锋利的差异点：表演 DSL（LLM 下高层指令而非裸参数）+ 五层加权软混合 + 五元音口型 + 模型无关的全参数语义 profile，三家都没把它当第一卖点。
  2. 多 Agent「团队群像」独一份：固定三人 + 委托流水线（写→审→修）+ 群聊/早安/朋友圈/梦境/真人秀；亲密度已改为事件驱动并持久化。
  3. 生命感从状态机升级到内驱力：energy/social/curiosity/comfort 指导自主行为，LLM 不可用时也不僵；情绪有 EMA 惯性而非硬切。
  4. Computer Use 在陪伴类里领先：SoM、zoom、batch、alpha-trim、全局急停、DPI 免疫、中文输入、高危拦截。
  5. 安全纵深罕见：六层防线、7 级×8 类、审批/沙箱/密钥加密/急停，意识接近 OpenClaw。
  6. 模型兼容面补齐：8 供应商 + 原生桥接 Claude/Gemini/Azure + 本地异构模型自动降级容错，纯聊天模型也能接。
  7. 工程交付密度高、且已能打包：TS strict、547 单测、约 11 万行自有代码；NSIS 安装包 + 绿色版 + 全套品牌图标已就绪，启动稳定。
  8. 办公生产力面最宽：约 60 工具 + CLI + REST，比另两家「更能干活」。

  • 功能蔓延：30+ 模块，单点深度不足，易稀释「3 分钟生命时刻」。

  • 核心循环测试薄：agentRunner 154KB 仅 4.1KB 测试；10 个超大文件、63 处 TODO；无 CI 覆盖率门禁。

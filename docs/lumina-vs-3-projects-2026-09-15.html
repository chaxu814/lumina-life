⑤ 定位象限（示意）
示意，非量化测量。
Lumina 真正站得住的优点
  1. 「意识同帧驱动身体」机制最锋利：一次推理同时输出 action/mood/speech，且 [Brain] 日志逐次可验证；三家都没把它当第一卖点（NEKO 多为「检测触发→LLM 只管说」，身体是状态机）。
  2. 多 Agent「团队群像」独一份：固定三人 + 委托流水线（写码→审查→修复闭环）+ 群聊/早安/朋友圈/梦境/真人秀/亲密度/人格冲突。
  3. 陪伴产品里罕见的安全纵深：accessControl/securityGuard/sandbox/approval/processSandbox/injectionGuard 六层、7 级×8 类、审批与密钥拦截，意识接近 OpenClaw。
  4. 办公生产力面最宽：54 个工具实现（文件/终端/git/LSP/OCR/深度研究/情报订阅）+ CLI + REST API，比另外两家「更能干活」。
  5. 本地优先 + AGPL/Apache 双许可，个人与商业都友好；中文本土场景与 QQ/钉钉/微信渠道。
  6. 交付密度高：约 6 周 10.6 万行自有代码、CUA 58 例测试、CI 三系统矩阵+打 tag 自动发版，且有清醒的工程治理文档。
问题与风险（直说）
  1. 成熟度断层：4 次提交、未公开、无 Release/外部贡献者；对手要么已上 Steam，要么近 5 万星，窗口在收窄。
  2. 广度>深度、功能蔓延：顶层 90+ 模块（luckyMode/loop/mission/timeCapsule/dream/realityShow/7角色/新闻/游戏化…），单点对拼都不够深。
  3. 三套口径没对齐：README 还在主打「三 Agent」，pitch 已改主打「生命体」、代码又加了「7 角色+Loop」；宣传「五维情绪/88+工具/v1.0」与代码实际（三维数值情绪/54 工具实现/计划回退 v0.1）有出入，公开后易被抓硬伤。
  4. 单体技术债：agentRunner 2907、pet-live2d.html 2727、main 1649、systemIpc 1569、petWindow 1514、proactiveEngine 1443 行；主 bundle 约 11MB。
  5. 形象与形态单薄：仅 1 个 Live2D（Mao），无 VRM/MMD；仅 Win 优先的 Electron，缺 Web/PWA/移动/Docker/headless。
  6. 实时语音非第一公民：这恰是 NEKO 最出体感、也最吃打磨的地方；供应商仅 6 家，无 AIRI 的本地推理栈与可复用包生态。
  7. 在途工作有丢失风险：101 个已改文件(+9004/−1731) + 166 个未跟踪新文件压了一个多月没提交。
⑥ 逐个对手：赢面与短板
vs N.E.K.O（最直接对手）
你占优：多 Agent 团队流水线与群像、安全纵深、办公工具面、LLM 驱动身体的机制叙事。
你落后：成熟度/商业化（对方已 Steam+工坊+社区）、5 种 Avatar+动捕、全双工实时语音、零配置开箱、跨端同一人格、14+ 供应商与免费模型、UGC 闭环。
五维记忆/主动搭话/屏幕理解/猫娘桌宠与它高度重合——差异必须靠「驱动身体 + 团队群像」讲得更锋利。
vs AIRI（不同赛道：VTuber/游戏）
你占优：桌面办公生产力、中文本土渠道、情感与团队社交层、安全意识。
你落后：「AI 真会玩游戏」这张王牌、VRM、Web/PWA/iOS 触达、monorepo 可复用 npm 包（xsai/unspeech/DuckDB 驱动）、WebGPU/CUDA/Metal 本地推理、国际化与贡献者社区。
vs OpenClaw（不同物种，别正面打）
你占优：人格/情绪/Avatar/消费级陪伴——它明确不做；中文与桌宠形态。
差距悬殊：工程/社区差几个量级，20+ 成熟渠道、配对安全、沙箱、headless/Docker/Nix/团队部署。
建议：像 N.E.K.O 一样用 A2A/MCP 把它当「手脚」，把自己的 6 个早期渠道与硬执行逐步外包，精力留给灵魂。
⑦ 回来第一件事：建议的下一步（按优先级）
0. 先止血：把压了一个多月的 101 改 + 166 新文件分批 commit（先 tsc/build/冒烟），别再让在途工作裸奔。
1. 统一口径：对外只讲 pitch 的「生命体」，按 release-v0.1-plan 重写 README 第一屏，三 Agent 降为彩蛋；先核准「情绪维度/工具数/版本号」，消除自相矛盾。
2. 冻结边缘模块（luckyMode/mission/realityShow/timeCapsule/7角色先藏起或标实验），把 {action,mood,speech} + 连续情绪向量（生命体设计第 2 层，性价比最高）+ 屏幕主动 磨到「3 分钟生命体时刻」，发 v0.1。
3. 与强者集成：A2A/MCP 接 OpenClaw 干硬任务；学 xsai 做薄供应商层，别逐个硬适配。
4. 补两块最短体验板：2–3 个授权清晰的形象/一键导入；打通实时语音链路。VRM 可排后。
5. 尽快公开 + 拍 pitch 里已写好的真机演示视频，用真实迭代换反馈，而不是继续闭门堆功能。

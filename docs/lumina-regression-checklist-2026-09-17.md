# Lumina 真机回归清单（2026-09-17）

> 无头环境能自动验证的纯逻辑/几何部分已写进单测（见文末）。
> 下列条目依赖真实显示器/麦克风/扬声器/网络，需要在真机逐项打勾。
> 建议分别在 **100%、125%、150%** 三档 Windows 缩放（设置→系统→显示）各跑一遍，
> 有 4K 屏再补 **200%**。每档都要重启一次应用（setShape / DPI 在启动时取值）。

## A. 透明窗 / 合成（"压视频黑屏"回归）

- [ ] 桌宠在桌面前方时，后面播放的视频/图片、网页动画**正常显示、不黑不花、不冻结**。
- [ ] 拖动/走路经过正在播放的视频区域，后方画面持续刷新（无 MPO/DComp 抢占）。
- [ ] 模型静止几秒后，窗口裁剪贴合身体，**透明区不挡鼠标**（点模型旁边能点到下层）。
- [ ] 打开聊天面板/右键菜单/工具栏时，窗口临时恢复整块，面板不被裁掉。
- [ ] 切换 125%/150% 后，裁剪位置与模型对齐，**不出现裁掉脑袋/手脚、或留大黑边**。

## B. alpha-trim（贴身裁剪）

- [ ] 不同模型下裁剪都贴身；走路、待机、摆手动作时不裁到模型。
- [ ] 带粒子/影子/飘落/光环特效的模型：特效被保留（有安全边距），不被削掉。
- [ ] 极端瘦小/居中模型时，单边内缩最多 45%（防误裁），不会把窗口裁空。
- [ ] 全透明帧/加载瞬间，窗口回退整块或上一次结果，**绝不出现窗口消失**。

## C. 全双工实时语音（本轮新增）

开关：右键桌宠 → 音频设置 → 「🎙 全双工实时对话」；开启后出现"聆听中/思考中/说话中"状态胶囊。

- [ ] 开启后能直接说话，桌宠**边听边答、逐句朗读**，口型跟随。
- [ ] **打断**：AI 正在说话时你开口，它立刻停嘴、改听你的新话（barge-in）。
- [ ] 说完一句→答完→自动回到聆听，可连续多轮，不用点按钮。
- [ ] 状态胶囊颜色随状态切换（蓝=聆听 / 黄=思考 / 绿=说话）。
- [ ] **在线识别**：Electron 内置 Web Speech 在你网络下是否出字（国内可能不通）。
      若 4 秒内 onstart 未触发（服务不可用）或报 network/service-not-allowed，应自动转本地。
- [ ] **本地识别（离线兜底）**：需先在项目目录 `npm install @xenova/transformers`，
      首次识别会自动下载 `Xenova/whisper-base`（约 290MB，多语含中文）。
      未安装时 UI 给出明确安装命令，不崩溃、不卡死。
- [ ] 回声：笔记本外放时 AI 说话不应把自己的 TTS 误判为用户（已做回声消除 +
      说话态只认最终结果两道防线；耳机最稳）。
- [ ] 麦克风选单（音频设置→选择麦克风）能选设备；开启时**没有自激啸叫**（已用 0 增益静音节点）。
- [ ] Edge TTS 与 IndexTTS（127.0.0.1:18927）两种引擎都能逐句播；IndexTTS 没开会自动回退 Edge。
- [ ] 关闭全双工后，麦克风释放、TTS 停止、胶囊消失；重启应用后开关状态被记住。
- [ ] 125%/150% 下胶囊位置与口型正常。

## D. Computer Use（猫爪 / 视觉 agent）

- [ ] 截屏回传画面清晰、比例正常（125%/150% 下不被拉伸或裁切）。
- [ ] **Set-of-Mark**：网格编号正确叠加在截图上，模型读编号即可命中。
- [ ] 点击落点准确：让它点任务栏/桌面图标/小按钮，**高缩放下不偏**。
- [ ] **zoom 局部放大**：粗选格→放大→细定位，两次坐标能还原到全局正确位置。
- [ ] **computer_batch**：一连串动作批量执行，顺序对、坐标不串。
- [ ] 中文输入走剪贴板粘贴，长文本/中文/Emoji 不丢字、不乱码，剪贴板事后还原。
- [ ] **Ctrl+Alt+X 全局急停**：动作执行中按下立刻停止，即时生效。
- [ ] 权限姿态符合设置：观察常开 / 点击输入逐次确认（按你最终拍板的姿态）。
- [ ] 4K 下标注 IPC 与截图耗时可接受（无明显卡顿）。

## E. UGC（导入自制 Live2D）

- [ ] 拖入/选择 `.model3.json` 能导入、出现在模型库、可切换。
- [ ] 缺贴图/缺动作的模型有清晰报错，不白屏；模型删除后不残留。
- [ ] 导入的模型透明窗/alpha-trim/口型/全双工同样工作。

## F. 原生协议（件③，需真实 key）

- [ ] 设置里分别接 Claude / Gemini / Azure：连通测试通过、能拉到模型列表、能对话、能流式。
- [ ] 工具调用回合、图片输入在三协议下正常（Anthropic tool_use / Gemini functionCall / Azure）。
- [ ] 本地 OpenAI 兼容端点（LM Studio 等）保持原行为，401 仍只对本地端点去鉴权重试。

## 当前无法在无头环境覆盖、必须真机确认的点

1. Web Speech 在内置 Chromium / 国内网络下是否真的出字（依赖 Google 语音服务）。
2. 本地 whisper 模型下载与真实识别率、延迟、VAD 切句手感。
3. setShape 在具体显卡/驱动（MPO/DComp）下对后方视频的实际合成效果。
4. PowerShell 截屏兜底在 DPI 虚拟化下返回的是物理还是逻辑分辨率（影响点击落点）。
5. 全双工边录边播的回声/延迟体感（必要时加 AEC/按键说话）。

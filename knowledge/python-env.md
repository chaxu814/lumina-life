# Lumina 操作知识库 — Python 环境

## 环境要求
- Python 3.10+ 推荐
- pip 最新版本

## 虚拟环境创建
```cmd
python -m venv .venv
.venv\Scripts\activate
```

## 常用 Python 库安装
```cmd
pip install requests numpy pandas openai httpx
```

## Whisper STT 安装 (可选)
```cmd
pip install openai-whisper
```

## 验证 Python 版本
```cmd
python --version
```

## How to Sign

There are two ways to agree to this CLA:

### Option A: Click-to-Sign (via GitHub CLA Assistant)

When you open your first Pull Request, the [CLA Assistant](https://github.com/contributor-assistant/github-action) bot will automatically ask you to sign this CLA by clicking a button. This is the recommended method.

### Option B: Include in Commit Message

Include the following line in your first Pull Request commit message:

